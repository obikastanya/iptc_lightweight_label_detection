# Anotasi manusia independen

Protokol lengkap (wajib dibaca sekali): [PROTOCOL.md](PROTOCOL.md)

| Folder / file | Untuk siapa | Isi |
|---|---|---|
| `kalibrasi/kalibrasi.xlsx` | Obi dan Anan (dikerjakan masing-masing, lalu didiskusikan bersama) | 10 artikel latihan di luar sampel |
| `obi/annotasi_obi.xlsx` | Obi saja | 100 artikel untuk dianotasi, urutan acak milik Obi |
| `anan/annotasi_anan.xlsx` | Anan saja | 100 artikel yang sama, urutan acak milik Anan |
| `ai_reference/ai_labels.xlsx` | **Jangan dibuka sebelum kedua annotator menyerahkan file** | Jawaban AI (buta) untuk 100 artikel |
| `_key/` | **Jangan dibuka oleh annotator** | Label redaksi dan sumber artikel (untuk analisis) |
| `_work/` | Analisis | Input buta untuk AI dan hasil mentahnya |

## Urutan kerja
1. Masing-masing mengerjakan `kalibrasi/kalibrasi.xlsx` sendiri (simpan salinan per orang, misalnya
   `kalibrasi_obi.xlsx` dan `kalibrasi_anan.xlsx`), lalu bandingkan dan diskusikan bersama.
2. Kerjakan file anotasi masing-masing sendiri, tanpa diskusi. Petunjuk ada di sheet "Petunjuk".
3. Serahkan file yang sudah selesai. Setelah keduanya diserahkan, file dicatat waktunya, baru kemudian
   jawaban dibandingkan dan perbedaan didiskusikan.
